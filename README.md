# 💫 About Me:
Linkedin Job Board (Group Project):<br>This was a group project that utilized a Linkedin scrapper API with all of Linkedin's jobs allowing users search for jobs based on various filters. Users who sign up had the ability to save jobs which are stored with MongoDB. This project was built using the MERN stack but may be updated to a slightly differnt stack and may contain user analytics and stronger user creditial requirements in the future.<br><br>
